# ovirus
A comprehensive machine learning pipeline for drug risk prediction using molecular fingerprints and descriptors. Extracts 7 feature types (MACCS, Morgan, TopoFP, AtomFP, RDKFP, Pattern, Descriptors) from SMILES, trains 8 classifiers including XGBoost and CatBoost, and generates ROC curves with risk probability predictions for NRDL drug candidates.
